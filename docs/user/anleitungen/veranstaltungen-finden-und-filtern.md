# Veranstaltungen finden und filtern

So finden Sie ein passendes Yoga-Angebot.

## Schritte

1. Klicken Sie in der Hauptnavigation auf **Veranstaltungen**.
2. Die Übersicht listet alle zukünftigen, veröffentlichten Angebote. Ausgebuchte Veranstaltungen zeigen den Hinweis **Warteliste** mit der aktuellen Anzahl wartender Einträge.
3. Wählen Sie im Dropdown **Filter** einen Typ:
   - **Kurs** – wiederkehrende Yogakurse
   - **Event** – einmalige Veranstaltungen
   - **Workshop** – thematisch fokussierte, meist längere Angebote
4. Klicken Sie auf den Titel einer Veranstaltung, um zur Detailseite zu gelangen.

## Ergebnis

Sie sehen nur passende Angebote und können sich auf der Detailseite anmelden.
