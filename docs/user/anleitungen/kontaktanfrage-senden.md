# Kontaktanfrage senden

Dieses How-To beschreibt, wie Sie über das Kontaktformular der Webseite eine Anfrage an
Sabrina Becker senden — zum Beispiel für ein privates Yoga-Event, einen Firmenkurs oder
eine Anfrage zu den Kursen in Bergen.

## Voraussetzungen

- Sie öffnen die Webseite in einem aktuellen Browser.
- Sie haben eine E-Mail-Adresse, unter der Sie erreichbar sind.

## Schritte

1. Öffnen Sie die Seite **Kontakt** über den Menüpunkt **Kontakt** (oder direkt `/kontakt`).
   Neben der Kontaktkarte steht das Formular **Anfrage senden**.
2. Füllen Sie die Pflichtfelder aus: **Name**, **E-Mail** und **Nachricht**. Optional
   ergänzen Sie **Telefon** und **Anlass / Gruppe** (z. B. „Junggesellinnenabschied").
3. Beschreiben Sie in **Nachricht**, wer Sie sind und welchen Termin Sie sich vorstellen.
4. Wählen Sie **Anfrage senden**. Sie sehen die Bestätigung, dass Ihre Anfrage angekommen
   ist, und erhalten eine Eingangsbestätigung per E-Mail.
5. Sabrina Becker erhält gleichzeitig eine Benachrichtigung über Ihre Anfrage und meldet
   sich persönlich bei Ihnen zurück.

## Hinweise

- Pflichtfelder sind mit `*` markiert.
- Der Versand ist begrenzt auf fünf Anfragen innerhalb von zehn Minuten; danach erscheint
  eine Meldung, und Sie können später erneut versuchen.
- Ihre Daten werden zum Zweck der Bearbeitung gespeichert; Details in der
  [Datenschutzerklärung](https://yoga-sabrinabecker.de/datenschutz).
- Das Formular fragt keine Gesundheitsinformationen ab — teilen Sie solche bitte auch in
  Ihrer Nachricht nicht mit.

## Ergebnis

Ihre Anfrage ist im System gespeichert und Sie erhalten eine Eingangsbestätigung per
E-Mail.
