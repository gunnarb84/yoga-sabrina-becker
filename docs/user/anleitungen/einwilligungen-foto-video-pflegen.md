# Einwilligungen zu Foto- und Videoaufnahmen pflegen

Veröffentlichen Sie Fotos und Videos von Teilnehmenden nur, wenn eine
Einwilligung vorliegt. Die Einwilligung erfassen Sie in der Teilnehmermaske —
entweder aus dem Online-Anmeldeformular (wird automatisch gespeichert) oder
aus dem unterschriebenen Papierformular.

## Schritte

1. Öffnen Sie **Teilnehmer** und klicken Sie auf den Namen der Teilnehmerin/des
   Teilnehmers.
2. Tragen Sie im Bereich **Einwilligung Foto- und Videoaufnahmen** ein:
   - **Einwilligung Fotos liegt vor** mit dem Datum **Einwilligung Fotos am**.
   - **Einwilligung Videos liegt vor** mit dem Datum **Einwilligung Videos am**.
3. Für Minderjährige genügt das unterschriebene Papierformular der
   Sorgeberechtigten — erfassen Sie die Einwilligung auf dieselbe Weise.
4. Bei einem Widerruf (z. B. per E-Mail eingegangen): Setzen Sie die
   betroffenen Haken zurück und tragen Sie **Widerruf am** und den
   **Widerrufsvermerk** (kurzer Text) ein.

## Hinweise

- Die Einwilligung ist freiwillig; Sie können die Maske auch ohne gesetzte
  Haken speichern.
- Beim Zurücksetzen eines Hakens wird das zugehörige Datum geleert.
- Die Einwilligung gilt für alle Veranstaltungen der Teilnehmerin/des
  Teilnehmers.
