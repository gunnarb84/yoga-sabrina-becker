# Zu einer Veranstaltung anmelden

Melden Sie sich für einen Kurs, ein Event oder einen Workshop an.

## Voraussetzungen

- Die Veranstaltung hat zukünftige Termine und ist buchbar.
- Sie haben eine gültige E-Mail-Adresse.

## Schritte

1. Öffnen Sie die Detailseite der gewünschten Veranstaltung.
2. Klicken Sie auf **Jetzt anmelden**.
3. Füllen Sie die Pflichtfelder **Vorname**, **Nachname** und **E-Mail** aus.
4. Wählen Sie eine **Zahlungsart**:
   - **Überweisung** – Sie erhalten eine Rechnung per E-Mail.
   - **Barzahlung vor Ort** – Sie zahlen beim ersten Termin.
5. Klicken Sie auf **Anmeldung absenden**.

## Ergebnis

- Ist ein Platz frei, wird Ihnen **Ihr Platz ist bestätigt** angezeigt.
- Ist die Veranstaltung ausgebucht, erhalten Sie einen Wartelistenplatz.
- Der Preis und der Anmeldestatus werden auf der Bestätigungsseite angezeigt.
