# Häufig gestellte Fragen

## Muss ich ein Konto anlegen, um mich anzumelden?

Nein. Sie geben bei der Anmeldung einfach Ihre Daten ein. Bereits bekannte E-Mail-Adressen aktualisieren die vorhandenen Teilnehmerdaten; neue Adressen legen einen neuen Teilnehmerdatensatz an.

## Was passiert, wenn eine Veranstaltung ausgebucht ist?

Sie erhalten einen Wartelistenplatz. Sobald ein Platz frei wird, kontaktiert Sie Sabrina Becker.

## Kann ich meine Anmeldung nachträglich ändern?

Eine nachträgliche Änderung über die öffentliche Webseite ist nicht vorgesehen. Wenden Sie sich bei Änderungswünschen direkt an die Verwaltung.

## Welche Zahlungsarten gibt es?

Aktuell werden Überweisung und Barzahlung vor Ort angeboten. Kostenlose Veranstaltungen erzeugen keinen Zahlungs- oder Belegaufkommen.
