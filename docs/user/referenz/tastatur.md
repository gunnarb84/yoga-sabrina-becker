# Tastaturbedienung

Die öffentliche Webseite ist für die Bedienung mit Maus und Tastatur optimiert. Alle interaktiven Elemente (Links, Schaltflächen, Formularfelder) sind über die Tab-Taste erreichbar und besitzen sichtbare Fokusmarkierungen.

## Öffentliche Webseite

| Taste | Wirkung |
|---|---|
| `Tab` | Zum nächsten interaktiven Element springen |
| `Shift + Tab` | Zum vorherigen interaktiven Element springen |
| `Enter` / `Leertaste` | Aktiviert den fokussierten Link oder die fokussierte Schaltfläche |

## Verwaltung

Die Verwaltung folgt der projektweiten Tastaturbelegung, sobald die entsprechenden Funktionstasten in den Modulen implementiert sind. Die aktuell verfügbaren Tastaturkürzel werden in den einzelnen Anleitungen dokumentiert.
