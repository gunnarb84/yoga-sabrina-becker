# Problembehebung

## Symptom: Die Detailseite zeigt „Die Veranstaltung wurde nicht gefunden."

- Der Link kann veraltet sein.
- Öffnen Sie die [Veranstaltungsübersicht](anleitungen/veranstaltungen-finden-und-filtern.md) und wählen Sie das Angebot erneut aus.

## Symptom: Das Formular lässt sich nicht absenden

- Prüfen Sie, ob alle mit * markierten Pflichtfelder ausgefüllt sind.
- Geben Sie eine gültige E-Mail-Adresse ein.
- Wenn Sie Gesundheitsinformationen angegeben haben, setzen Sie das Häkchen bei der Einwilligung.

## Symptom: „Warteliste" wird angezeigt

- Die Veranstaltung ist ausgebucht.
- Sie können sich trotzdem anmelden und erhalten einen Wartelistenplatz.
