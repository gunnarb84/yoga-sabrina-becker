# Startseite anzeigen

## Meta
- **State:** Implemented

## User Story
Als Besucher möchte ich eine Startseite sehen, die die aktuellen Yoga-Angebote und wichtigsten
Informationen übersichtlich darstellt, damit ich mich schnell orientieren kann.

## Description
Die Startseite ist die Einstiegsseite der öffentlichen Webseite. Sie zeigt eine kurze
Vorstellung, das aktuelle Kursangebot und Links zu den wichtigsten Rubriken. Das Layout
orientiert sich am vorhandenen Design-Entwurf `homepage-entwurf.html`, ist aber als eigenständige
Seite umgesetzt.

## Akzeptanzkriterien
- Die Startseite ist unter `/` erreichbar.
- Die Startseite zeigt das Logo und den Namen der Anbieterin an.
- Die Startseite zeigt bis zu sechs zukünftige, veröffentlichte Veranstaltungen (`Activity`) mit
  Titel, Kurzbeschreibung, Bild, Preis und Hinweis auf Buchbarkeit/Warteliste.
- Die Startseite enthält einen Link zur vollständigen Veranstaltungsübersicht.
- Die Startseite enthält Links zu den statischen Seiten Impressum, AGB und Datenschutz.
- Ist keine Veranstaltung veröffentlicht, wird ein Hinweis auf kommende Angebote angezeigt.
- Die Startseite ist im Browser über die Navigationsleiste jederzeit erreichbar.
