# Anfrageformular anzeigen

## Meta
- **State:** Implemented

## User Story
Als Besucher möchte ich auf der Kontaktseite ein Anfrageformular ausfüllen können, damit ich
eine Anfrage stellen kann, ohne selbst eine E-Mail zu schreiben.

## Description
Auf der Kontaktseite steht neben der Kontaktkarte ein Formularkarte. Sie ersetzt den
bisherigen E-Mail-Hinweis. Das Formular ist Teil der öffentlichen Seite und verlinkt die
Datenschutzerklärung.

## Akzeptanzkriterien
- Auf der Kontaktseite ist neben der Kontaktkarte ein Anfrageformular sichtbar.
- Das Formular enthält die Felder `name`, `email`, `phone`, `topic` und `message`.
- Das Formular zeigt an, welche Felder Pflichtfelder sind (`name`, `email`, `message`).
- Das Formular enthält neben der Versandaktion einen Link auf die Datenschutzerklärung.
- Das Formular enthält keine Eingabemöglichkeit für Gesundheitsinformationen.
