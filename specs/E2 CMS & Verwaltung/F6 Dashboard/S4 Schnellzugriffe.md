# Schnellzugriffe

## Meta
- **State:** Implemented

## User Story
Als Administratorin möchte ich die häufigsten Arbeitsgänge direkt vom Dashboard aus
erreichen, damit ich nicht erst durch die Navigation muss.

## Description
Das Dashboard zeigt unter „Schnellzugriffe" Links zu den am häufigsten genutzten
Masken. Die Links rufen ausschließlich bestehende Ansichten auf; es gibt keine
Erfassung im Dashboard selbst (siehe Idee I7).

## Akzeptanzkriterien
- Das Dashboard zeigt den Schnellzugriff „Bareinnahme erfassen"; sein Sprung öffnet
  die Maske zur Erfassung einer Bareinnahme.
- Das Dashboard zeigt den Schnellzugriff „Aktivität anlegen"; sein Sprung öffnet die
  Maske zum Anlegen einer Aktivität.
- Das Dashboard zeigt den Schnellzugriff „Anmeldungen"; sein Sprung öffnet die
  Anmeldungsliste.
